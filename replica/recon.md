# Recon: Dotify (dotify.fun)

Разведка по правилам `/replica-recon`: только публичные страницы сайта (главная, /faq, /subs, /status,
manifest) и их же публичные скриншоты приложения. Исходники, API и аккаунты не трогались.
Цель — не клон, а список механик, которые имеет смысл перенести в Vicinity.

## Что это
Мультиплатформенный музыкальный плеер (Windows, macOS, Linux, Android APK, iOS через sideload),
который объединяет каталоги YouTube, Spotify, VK Музыки, Яндекс Музыки, Deezer, Apple Music и SoundCloud.
Ядро продукта — **чужие каталоги через собственный прокси** («Медиа», «Прокси» на странице статуса,
FAQ про Zapret и DNS). Монетизация: подписка на 30/90/180/365 дней за «эксклюзивные темы, расширенную
синхронизацию, бета-сборки». Социальное доказательство на лендинге: «139 147 пользователей • 3 263 онлайн».

## Компоненты
Пилюля-шапка с размытием; карточка фичи (иконка, заголовок, подпись); слайдер скриншотов с точками;
аккордеон FAQ с бейджем и «Copy link» на якорь; светофор-строка статуса; чипы фильтров; карточка трека;
круглый аватар артиста с бейджем источника; круглые кнопки поверх обложки; бейдж сервиса-источника
(логотип в круге) — везде, где есть трек.

## Что нельзя клонировать (skip)
- Сами каталоги и стримы YouTube/Spotify/VK/Яндекса/Apple/Deezer: чужой контент, обход условий сервисов.
- «Скачивание в MP3/FLAC без ограничений» и прокси/Zapret для обхода блокировок: юридический риск.
- Счётчики пользователей и их сообщество.

## Размер
10 экранов, 6 потоков, 6 сущностей. Трудное: интеграция с каталогами (вне scope), синхронный текст песен,
кроссплатформенные сборки. Для Vicinity — не клон, а заимствование механик (см. features.csv): размер **S–M**.

## Что взять в Vicinity (приоритет)
1. **«Слушаю сейчас» в статусе** — аналог Discord RPC наоборот: у Vicinity уже есть трек в профиле
   (`/music/search`), осталось показывать его как активность в панели пользователя и в списке друзей.
2. **Слушать вместе в голосовом канале** — очередь треков на канал, превью из каталога Apple Music
   (30 с) уже доступно через существующий поиск; кнопка «Similar» → «Ещё такого же».
3. **Страница /status** (сервер, голос, TURN, почта, push) — одна страница из `/api/v1/health`.
4. **FAQ с якорями и «Copy link»** и таблица сборок по платформам на экране «Приложения».
5. **Чипы-фильтры в поиске** (Все / Сообщения / Файлы / Ссылки / Люди) — у Vicinity поиск уже есть.
6. **Динамический акцент от обложки** для карточки профиля с музыкой (у нас уже есть свой акцент).
7. Счётчик «в сети / всего» на странице входа как социальное доказательство.

## OWASP Top 10

- **A01 контроль доступа** — в целом сильно: все эндпоинты под AuthFilter, admin через `developer=1`, `Access::channel` везде, IDOR по сообщениям/пинам/сессиям/подпискам проверен. Остаток: `/uploads/**` отдаётся без авторизации по случайному имени — вложение из лички доступно всем, кто знал ссылку (удаление сообщения теперь удаляет файл ✅); рядовой участник может создавать каналы на сервере (10/мин) — решить, нужно ли ограничить владельцем.
- **A02 настройки** — `BACKEND_BIND` по умолчанию `0.0.0.0` (десктоп по HTTP без TLS); `trusted_proxies` на все приватные сети: через docker-proxy можно подделать `X-Real-IP` и обойти лимиты по IP; `client_max_body_size 110M` действует и на JSON без авторизации. Заголовок `Server` убран ✅.
- **A03 цепочка поставок** — низкий: образы и Actions по тегам, не по digest/sha; `react`, `vite`, `lucide-react` с `^`.
- **A04 криптография** — чисто, кроме инвайт-кодов (исправлено ✅) и старого формата хэша для давно не входивших (принудительный сброс пароля для `needsRehash` — план).
- **A05 инъекции** — чисто: SQL параметризован (конкатенация только констант и белых списков), команд ОС нет, XSS в web нет (markdown через React, ссылки только `https?`), загрузки по magic bytes, SVG/HTML запрещены.
- **A06 дизайн** — исправлены подарки, push, WS-лимиты ✅. Остаток: результаты игры «Активности» (`PlayController.cc` `floor/kills/won`) принимаются с клиента — таблица рекордов накручивается одним POST; «Переправа» создаёт клиента на каждый `hello` без лимита на IP.
- **A07 аутентификация** — lockout по аккаунту ✅; токен в `localStorage` и в `?token=` для `/ws` (план: токен первым текстовым кадром); отключение 2FA без пароля и без лимита попыток (`AccountController.cc`).
- **A08 целостность** — десктоп обновляется с сервера без подписи кода (только TLS + sha512 из `latest.yml` рядом); автообновление прода — любой пуш в ветку. План: подпись NSIS, деплой с подписанных тегов.
- **A09 логирование** — аудит админа и неудачные входы добавлены ✅.
- **A10 ошибки** — `e.what()` закрыт ✅; остаток: отдельный `client_max_body_size` для `/api/` без загрузок; allow-list хостов push-сервисов.

## Топ-5 дальше (по опасности)

1. **Внешний мониторинг и бэкапы вне VPS.** Uptime-чек на `/api/v1/health`, `VICINITY_ALERT_URL`, cron на `backup.sh`, `rclone`/`scp` копии наружу, разовая проверка восстановления.
2. **Автовыкат без гейта и без отката.** `autoupdate.sh`: проверять статус CI коммита или тянуть только теги; хранить предыдущий образ и `rollback.sh`.
3. **Бэкенд от root и 8080 наружу.** `USER app` в `deploy/Dockerfile` (с `chown` тома при обновлении), `BACKEND_BIND=127.0.0.1` по умолчанию, `trusted_proxies` только на адрес контейнера web.
4. **Дубли сообщений при повторе.** Сохранять `nonce` в `messages` с `UNIQUE(author_id, nonce)` и возвращать существующее.
5. **Отключение 2FA и токен в URL.** Пароль + лимит попыток на `2fa/disable`; токен для `/ws` первым кадром; подпись десктопного установщика.

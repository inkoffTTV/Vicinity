# Vicinity

Desktop real-time messenger built with C++, Qt/QML and Drogon.

## Features

- Direct messages and real-time WebSocket messaging
- Servers and channels
- Voice channels
- Profiles, presence and roles
- Message reactions, editing and deletion
- Image attachments
- WebRTC 1:1 calls
- Opus audio and H264 video
- Camera and screen sharing
- Theme and UI customization

## Stack

- C++17
- Qt 6 / QML
- Drogon
- SQLite
- WebSocket
- WebRTC / libdatachannel
- Opus / H264
- CMake

## Security

- Bearer-token authentication
- PBKDF2 password processing
- Hashed session tokens
- Authentication and rate-limit filters

## Platforms

- Windows
- Linux

## Development

AI-assisted development tools were used as part of the engineering workflow.

# Vicinity для Windows

Приложение — окно Electron с веб-клиентом с сервера (`APP_URL` в `src/main.js`). Дизайн и функции
обновляются вместе с сайтом; само приложение отвечает за трей, уведомления, выбор экрана для показа
(со звуком компьютера), автозапуск, автообновление и оверлей для игр.

## Меню картинок и текста (1.3.0+)

`src/preload.js` отдаёт веб-клиенту `window.vicinityDesktop.saveImage(url, name)` (диалог «Сохранить как»;
`true` — сохранено, `null` — отмена, `false` — не удалось), `saveImages([{url, name}])` (папка выбирается один раз,
не больше 100 файлов; число сохранённых или `-1` при отмене) и `copyImage(url)` (PNG/JPEG до 50 МБ в буфер обмена).
Принимаются только запросы главного окна со страницы Vicinity и адреса картинок того же сервера
(`/uploads/attachments/<id>.png|jpg|jpeg|gif|webp`); расширение файла берётся из адреса, а не из имени от
отправителя. Скачивание идёт через `downloadURL` с куками сессии, путь ставится в `will-download`, тайм-аут — 60 с.
Правая кнопка по тексту — системное меню (вырезать, копировать, вставить, выделить всё) с проверкой орфографии
ru и en-US. Без этих методов (старые версии) веб сохраняет и копирует как в браузере. Подробнее — docs/API.md §23.1.

## Ссылки открываются в приложении (1.2.0+)

Установщик регистрирует протокол `vicinity://`: кнопка «Открыть в приложении» на странице приглашения
(`/invite/<код>`) в браузере ведёт на `vicinity://invite/<код>`, и приложение открывает этот экран в уже
запущенном окне. Ссылки на свой сайт внутри окна (приглашения, подарки, профили, чаты) открываются здесь же,
а не во внешнем браузере. Веб-клиент получает адрес событием `vicinity-open` (`web/src/lib/router.ts`).

## Оверлей для игр (1.1.0+)

Прозрачное окно поверх всего (`/overlay` с того же сервера): участники голосового канала с индикатором
речи, входящий звонок, свежие сообщения из личек и бесед. Клики проходят сквозь него. Включается в
Настройки → «Оверлей в играх», из меню трея или клавишами Ctrl+Shift+O; угол экрана — там же.
Настройки лежат в `%APPDATA%/vicinity-desktop/overlay.json`. Игры в эксклюзивном полноэкранном режиме
рисуются мимо любых оверлеев — нужен оконный режим без рамки.

## Сборка

```sh
npm install
node node_modules/electron/install.js   # если npm не скачал Electron сам
npm run dist                            # → dist/Vicinity-Setup-<версия>.exe и dist/latest.yml
```

В терминале VS Code перед `npm start` сбросьте `ELECTRON_RUN_AS_NODE` — иначе Electron запустится как Node.

## Выпуск версии

1. Поднять `version` в `package.json`, собрать `npm run dist`.
2. Скопировать на сервер в `~/vicinity/deploy/downloads/`: `Vicinity-Setup-<версия>.exe`,
   его `.blockmap`, `latest.yml`, и тот же установщик под именем `Vicinity-Setup.exe` (ссылка «Скачать»).
3. Установленные приложения сами найдут `latest.yml`, скачают обновление и предложат перезапуск.

Установщик не подписан сертификатом — Windows SmartScreen при первом запуске покажет предупреждение
(«Подробнее» → «Выполнить в любом случае»).

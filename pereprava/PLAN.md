# План: Переправа 0.3 → полноценная игра с сетевым режимом

Отмечаю прогресс по ходу работы. Каждая фаза заканчивается коммитом и пушем; после каждой фазы
игра запускается и играбельна.

## Фаза 1. Структура проекта
- [x] Прототип сохранён как есть: `legacy/pereprava.html`
- [x] Монорепо на npm workspaces: `packages/shared`, `packages/client`, `packages/server`
- [x] Vite + TypeScript, three.js 0.170.0 из npm (закреплённая версия)
- [x] Свет и цвет подстроены под r128: ColorManagement выключен, вывод в LinearSRGB, интенсивность ×π
- [x] Вся игровая логика в `shared`: детерминированная, тик 30 Гц, без three.js и DOM
  - [x] карта (тот же генератор и порядок вызовов — те же деревья), юниты, бой, вышки, кристаллы
  - [x] волны крипов, золото, опыт, уровни, лавка, фонтаны, бот-Громила с ИИ прототипа
  - [x] единая «труба» урона (физический/магический/чистый, броня, щит), модификаторы, способности
  - [x] снимки мира с туманом войны (`makeSnapshot`)
- [x] Клиент рисует только снимки: интерполяция, процедурная анимация, пул эффектов
- [x] Режим против бота — локально на той же симуляции (`LocalSession`)
- [x] Отладка: `#debug` (`window.__g`: старт, шаги, касты, приказы, вся карта), `#x4` (ускорение)
- [x] Первый тест: детерминизм

## Фаза 2. Сетевая игра
- [x] Сервер Node.js + ws, авторитарный, комнаты по коду
- [x] Протокол: move, attack, cast с точкой, buy, use item, ping
- [x] Клиент: буфер снимков, интерполяция, предсказание своего героя с коррекцией
- [x] Лобби: создать, войти по коду или ссылке, выбор героя, «Готов», 1v1 и 2v2, боты в пустых слотах
- [x] Туман войны на сервере (клиент не получает врагов вне видимости)
- [x] Переподключение в течение 60 с
- [x] Кнопка «С другом» в меню
- [x] Проверено двумя вкладками: создание, вход по ссылке, «Готов», матч, туман, перезагрузка вкладки → возврат в матч

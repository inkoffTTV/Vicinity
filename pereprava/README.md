# Переправа

Браузерная MOBA для телефона и компьютера. Одна линия через реку, по две вышки и кристалл у каждой
стороны, волны крипов, лесные лагеря и руна. Пять героев с тремя умениями и ультимейтом на 6 уровне,
лавка из 14 предметов. Играть можно против бота (три уровня сложности) или с друзьями по сети —
1 на 1 и 2 на 2 по коду комнаты или ссылке; пустые места занимают боты. Матч длится около 15 минут.

Всё своё: модели собраны из примитивов, звук синтезируется в браузере, имена и умения придуманы
для этой игры. Сторонние библиотеки и шрифты перечислены в [ASSETS.md](ASSETS.md).

## Запуск у себя

Нужен Node.js 22.

```sh
npm install
npm run dev          # клиент: http://localhost:5173 (против бота работает сразу)
npm run dev:server   # игровой сервер для режима «С другом»: порт 8787
```

Клиент в режиме разработки сам проксирует `/ws` на `localhost:8787`, так что для сетевой игры
достаточно двух команд выше в двух терминалах. Откройте игру во второй вкладке или на телефоне в той
же сети (Vite покажет адрес вида `http://192.168.x.x:5173`).

| Команда           | Что делает                                                                 |
| ----------------- | -------------------------------------------------------------------------- |
| `npm run build`   | сборка клиента (`packages/client/dist`) и сервера (`packages/server/dist`) |
| `npm test`        | юнит-тесты симуляции (vitest)                                              |
| `npm run e2e`     | smoke-тесты в браузере (Playwright, десктоп и телефон)                     |
| `npm run check`   | типы + линтер + тесты                                                      |
| `npm run lint`    | ESLint                                                                     |
| `npm run format`  | Prettier                                                                   |
| `npm run balance` | матчи бот против бота: средняя длительность и победы                       |

Выложить на сервер — [DEPLOY.md](DEPLOY.md) (Docker, nginx, HTTPS через certbot).

Для отладки: `#debug` в адресе даёт `window.__g` (старт матча, шаги симуляции, касты, вся карта),
`#x4` ускоряет игру в 4 раза, `#fps` показывает кадры в секунду и число вызовов отрисовки.

## Управление

| Телефон                     | Компьютер                               | Действие                            |
| --------------------------- | --------------------------------------- | ----------------------------------- |
| касание земли               | клик                                    | идти                                |
| касание врага               | клик по врагу                           | атаковать                           |
| вести пальцем               | —                                       | герой идёт за пальцем               |
| кнопки Q W E R справа внизу | Q W E R (прицел — курсор)               | умения; R — ультимейт с 6 уровня    |
| касание предмета            | 1–6                                     | применить предмет                   |
| «Лавка»                     | B                                       | лавка (покупать — у своего фонтана) |
| касание миникарты           | клик по миникарте                       | идти в точку                        |
| долгое нажатие на миникарте | G, Alt+клик, правая кнопка на миникарте | пинг союзникам (с Shift — «опасно») |
| касание счёта               | Tab (держать)                           | таблица матча                       |
| щипок                       | колесо                                  | приблизить / отдалить               |
| —                           | S                                       | стоп                                |

В настройках: качество графики, тени, время суток (как в системе / день / ночь), громкость.

## Как устроено

Симуляция детерминированная и общая для всех режимов: тик 30 Гц, одно зерно случайности, никакого
three.js и DOM. Против бота она крутится прямо в браузере, в сети — на сервере, который рассылает
клиентам снимки мира с туманом войны. Клиент только рисует снимки и отправляет приказы; свой герой
предсказывается, чужие плавно интерполируются.

```
pereprava/
├── packages/
│   ├── shared/              общая логика — работает и в браузере, и на сервере
│   │   ├── src/map.ts         карта: высоты, река, деревья, вышки, лагеря, руны
│   │   ├── src/data/          герои, предметы, сложность бота
│   │   ├── src/sim/world.ts   мир и тик: юниты, урон, смерть, золото, опыт, волны, вышки
│   │   ├── src/sim/abilities.ts  умения (реестр: данные + функции + подсказки для ИИ)
│   │   ├── src/sim/modifiers.ts  эффекты: щит, оглушение, замедление, ауры, невидимость…
│   │   ├── src/sim/ai.ts      бот: один ИИ для любого героя
│   │   ├── src/sim/jungle.ts  нейтралы и руны
│   │   ├── src/snapshot.ts    снимок мира для игрока (туман войны)
│   │   ├── src/protocol.ts    сообщения клиент ↔ сервер
│   │   ├── scripts/balance.ts бот против бота для баланса
│   │   └── test/              юнит-тесты
│   ├── client/              браузер: Vite + TypeScript + three.js
│   │   ├── index.html         разметка меню и интерфейса
│   │   └── src/
│   │       ├── app.ts         состояния (меню, поиск, выбор героя, загрузка, матч, итоги)
│   │       ├── game/          локальная и сетевая сессии, ввод (тач, мышь, клавиши)
│   │       ├── render/        сцена, ландшафт, модели, анимации, эффекты, инстансинг
│   │       ├── ui/            HUD, лавка, лобби, экраны, хранилище настроек
│   │       ├── audio/         процедурный звук на Web Audio
│   │       ├── net/           подключение к серверу
│   │       └── styles.css     дизайн-система и стили
│   └── server/              Node.js + ws: комнаты, лобби, переподключение, /health
├── e2e/                     Playwright smoke
├── deploy/nginx/            конфиги nginx для Docker
├── Dockerfile, docker-compose.yml, .env.example
├── legacy/pereprava.html    прототип 0.3, с которого всё началось
├── PLAN.md                  план по фазам и прогресс
├── DECISIONS.md             спорные решения и почему так
├── DEPLOY.md                выкладка на сервер
└── ASSETS.md                сторонние ресурсы и лицензии
```

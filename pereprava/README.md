# Переправа

Браузерная MOBA для телефона и компьютера. Три карты: 1 на 1 — одна линия через реку, 2 на 2 — две
линии, 3 на 3 — три (верх, центр, низ); на каждой линии по две вышки у каждой стороны, кристалл
открывается, когда пала внутренняя вышка любой линии. Волны крипов, лесные лагеря и руна.
24 героя шести ролей (стрелки, маги, танки, убийцы, поддержка, бойцы), у каждого три умения и
ультимейт на 6 уровне. Лавка из 30 предметов с рецептами и рюкзаком. Играть можно против ботов
(три уровня сложности) или с друзьями по сети — по коду комнаты или ссылке, в том числе прямо
в звонке Vicinity; пустые места занимают боты.

Всё своё: модели собраны из примитивов, звук синтезируется в браузере, имена и умения придуманы
для этой игры. Сторонние библиотеки и шрифты перечислены в [ASSETS.md](ASSETS.md).

## Запуск у себя

Нужен Node.js 22.

```sh
npm install
npm run dev          # клиент: http://localhost:5173 (против бота работает сразу)
npm run dev:server   # игровой сервер для режима «С другом»: порт 8787
```

Клиент в режиме разработки сам проксирует `/ws` на `localhost:8787`, так что для сетевой игры
достаточно двух команд выше в двух терминалах. Откройте игру во второй вкладке или на телефоне в той
же сети (Vite покажет адрес вида `http://192.168.x.x:5173`).

| Команда           | Что делает                                                                 |
| ----------------- | -------------------------------------------------------------------------- |
| `npm run build`   | сборка клиента (`packages/client/dist`) и сервера (`packages/server/dist`) |
| `npm test`        | юнит-тесты симуляции (vitest)                                              |
| `npm run e2e`     | smoke-тесты в браузере (Playwright, десктоп и телефон)                     |
| `npm run check`   | типы + линтер + тесты                                                      |
| `npm run lint`    | ESLint                                                                     |
| `npm run format`  | Prettier                                                                   |
| `npm run balance` | матчи бот против бота: средняя длительность и победы                       |

Выложить на сервер — [DEPLOY.md](DEPLOY.md) (Docker, nginx, HTTPS через certbot).

Для отладки: `#debug` в адресе даёт `window.__g` (старт матча, шаги симуляции, касты, вся карта),
`#x4` ускоряет игру в 4 раза, `#fps` показывает кадры в секунду и число вызовов отрисовки.

## Управление

| Телефон                     | Компьютер                               | Действие                            |
| --------------------------- | --------------------------------------- | ----------------------------------- |
| касание земли               | клик (левой или правой)                 | идти                                |
| касание врага               | клик по врагу (подсвечен под курсором)  | атаковать                           |
| —                           | A, затем клик                           | атака с передвижением               |
| вести пальцем               | —                                       | герой идёт за пальцем               |
| касание кнопки Q W E R      | Q W E R, затем клик по цели или точке   | умение (R — ультимейт с 6 уровня)   |
| «+» над кнопкой умения      | Ctrl + Q W E R или «+»                  | изучить / повысить умение           |
| кнопка TP, затем вышка      | T, затем клик по вышке или миникарте    | свиток телепорта (3 с)              |
| «Курьер»                    | C или «Курьер»                          | привезти вещи из тайника            |
| двойное касание портрета    | двойной клик по портрету                | камера к герою                      |
| потянуть от кнопки умения   | —                                       | прицел пальцем; вернуть — отмена    |
| —                           | Esc или правая кнопка                   | отменить прицел                     |
| касание предмета            | 1–6                                     | применить предмет                   |
| «Лавка»                     | B                                       | лавка (покупать — у своего фонтана) |
| кнопка цели под «Лавкой»    | клик по ней                             | купить следующую часть цели         |
| касание миникарты           | клик (левой или правой) по миникарте    | идти в точку                        |
| долгое нажатие на миникарте | G, Alt+клик                             | пинг союзникам (с Shift — «опасно») |
| касание счёта               | Tab (держать)                           | таблица матча                       |
| щипок                       | колесо                                  | приблизить / отдалить               |
| —                           | S                                       | стоп                                |

В настройках: умения «с прицелом» или «сразу по курсору», качество графики, тени, время суток
(как в системе / день / ночь), громкость. Карта для игры с ботами выбирается в меню.

## Герой: уровни, мана, атрибуты

Уровни 1–15, за каждый — очко навыка. Обычное умение качается до 4 (уровень N — с уровня героя 2N−1),
ультимейт до 3 (на 6, 10 и 14 уровне). Умения тратят ману. Атрибуты: сила (здоровье и его
восстановление), ловкость (броня и скорость атаки), интеллект (мана и её восстановление);
главный атрибут героя — по роли, предметы с атрибутами усиливают и урон по главному. Герой
разворачивается не мгновенно: тяжёлые — медленнее.

Нижняя панель: слева живой портрет, уровень, атрибуты, урон, броня, скорость и темп атаки; в центре
умения (уровни, стоимость маны, перезарядка, синяя подсветка — не хватает маны) и полосы здоровья
и маны с восстановлением; справа инвентарь 3×2, рюкзак, нейтральный слот, свиток телепорта,
золото, лавка и курьер.

## Лавка

Покупать можно где угодно: у фонтана вещь сразу в инвентаре, вдали — в тайнике, и курьер везёт её
герою (курьера можно убить — тогда вещи вернутся в тайник). Продавать — только у фонтана. Свиток
телепорта ложится в отдельный слот (до 3). Нейтральные предметы выпадают из лесных зверей. 30 предметов трёх уровней: базовые,
промежуточные и итоговые; составной предмет собирается из 2–3 частей и доплаты за рецепт, части
в инвентаре и рюкзаке засчитываются в цену на любой глубине. Разделы «Рекомендуемое» (под героя),
«Расходники», «Атака», «Защита», «Магия», «Скорость», «Итоговые» и поиск по названию. В карточке —
что даёт предмет, из чего собирается и во что входит. «Сделать целью» — и кнопка у лавки покупает
следующую часть одним нажатием. Шесть основных слотов и рюкзак на три (в рюкзаке предметы не
работают). Продажа в первые 10 с после покупки возвращает всё уплаченное, потом — половину цены.

## Как устроено

Симуляция детерминированная и общая для всех режимов: тик 30 Гц, одно зерно случайности, никакого
three.js и DOM. Против бота она крутится прямо в браузере, в сети — на сервере, который рассылает
клиентам снимки мира с туманом войны. Клиент только рисует снимки и отправляет приказы; свой герой
предсказывается, чужие плавно интерполируются.

# Переправа

Браузерная MOBA для телефона и компьютера: одна линия, река, вышки и кристаллы, герои с тремя
способностями и ультимейтом. Против бота или с друзьями по сети (1v1 и 2v2).

> Подробное описание, управление и структура проекта — в конце работы над фазами.
> План и прогресс — [PLAN.md](PLAN.md), решения — [DECISIONS.md](DECISIONS.md).

## Быстрый старт

```sh
npm install
npm run dev          # клиент: http://localhost:5173
npm run dev:server   # сервер для сетевой игры: http://localhost:8787
npm test             # тесты симуляции
```

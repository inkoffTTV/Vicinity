# Vicinity Web

Браузерная версия Vicinity (React + TypeScript + Vite). Работает с тем же бэкендом,
что и десктоп-клиент: REST `/api/v1/*`, WebSocket `/ws`, файлы `/uploads/*`.

## Что умеет

- вход и регистрация, сессия сохраняется между перезагрузками
- личные сообщения, беседы, серверы и текстовые каналы
- сообщения в реальном времени, редактирование (в т.ч. ↑ для последнего), удаление, реакции
- отправка без ожидания сервера: сообщение сразу в ленте, при ошибке — «Повторить»;
  черновики по каналам; подгрузка истории (если сервер её поддерживает)
- устойчивость к обрывам: проверка соединения ping/pong, переподключение с догонялкой
  пропущенного, при недоступном сервере вход не сбрасывается
- картинки: кнопка «＋», вставка из буфера (Ctrl+V), перетаскивание
- друзья: поиск, заявки, принятие/отклонение, статусы присутствия
- серверы: создание, вступление по коду, создание каналов, участники, удаление участников владельцем
- профиль: имя, о себе, местоимения, цвет, статус, аватар и баннер
- непрочитанные, уведомления браузера, мобильная вёрстка, светлая/тёмная тема

Пока **нет** голосовых каналов и звонков — они работают только в десктоп-клиенте
(в вебе видно, кто сидит в голосовом канале, а входящий звонок можно отклонить).

## Разработка

```bash
cd web
npm install
npm run dev            # http://localhost:5173, API проксируется на http://localhost:8080
# другой бэкенд:
VICINITY_BACKEND=http://IP_VPS:8080 npm run dev
```

`npm run build` — проверка типов и сборка в `web/dist`.

E2E-тесты (Playwright) поднимают собранный бэкенд и `vite preview`:

```bash
VICINITY_SERVER_BIN=../build/backend/VicinityServer npx playwright test
```

## Продакшен

Собирается и раздаётся nginx-контейнером из `deploy/` (сервис `web`), который проксирует
`/api`, `/ws` и `/uploads` на сервер. Инструкция — в [DEPLOY-VPS.md](../DEPLOY-VPS.md#веб-версия).

# Vicinity Web

Браузерная версия Vicinity (React + TypeScript + Vite). Работает с тем же бэкендом,
что и десктоп-клиент: REST `/api/v1/*`, WebSocket `/ws`, файлы `/uploads/*`.

## Что умеет

- вход и регистрация, сессия сохраняется между перезагрузками
- личные сообщения, беседы, серверы и текстовые каналы
- сообщения в реальном времени, редактирование (в т.ч. ↑ для последнего), удаление, реакции
- отправка без ожидания сервера: сообщение сразу в ленте, при ошибке — «Повторить»;
  черновики по каналам; подгрузка истории (если сервер её поддерживает)
- устойчивость к обрывам: проверка соединения ping/pong, переподключение с догонялкой
  пропущенного, при недоступном сервере вход не сбрасывается
- картинки: кнопка «＋», вставка из буфера (Ctrl+V), перетаскивание
- друзья: поиск, заявки, принятие/отклонение, статусы присутствия
- серверы: создание, вступление по коду, создание каналов, участники, удаление участников владельцем
- профиль: имя, о себе, местоимения, цвет, статус, аватар и баннер
- непрочитанные, уведомления браузера, мобильная вёрстка, светлая/тёмная тема
- голосовые каналы серверов и голосовые комнаты личек/бесед — вместе с десктоп-клиентом:
  индикатор речи, выключение микрофона и звука, выбор микрофона и динамиков, усиление и громкость
  (запоминаются), повторный вход после обрыва связи
- звонки 1:1 с десктопом и между браузерами: входящий с мелодией, камера и показ экрана,
  окно звонка сворачивается в «таблетку»
- настройки сервера (владельцу): название и иконка, ссылка-приглашение и новый код, участники
  (поиск, исключение, бан), список банов, удаление сервера; участнику — «Покинуть сервер»;
  переименование и удаление каналов
- беседы: панель участников — пригласить, переименовать, покинуть, удалить (владелец)
- в списке личек и бесед — последнее сообщение и время, свежие сверху
- настройки: профиль, аккаунт (смена пароля, активные сеансы, выход на других устройствах),
  внешний вид (тема, акцентный цвет, компактная лента, размер шрифта, без анимаций), уведомления,
  голос и видео
- адреса экранов (`/channels/@me/<id>`, `/channels/<сервер>/<канал>`), «назад/вперёд» в браузере,
  ссылки-приглашения `/invite/<код>`
- Ctrl+K — быстрый переход, Alt+↑/↓ — соседний канал, Alt+Shift+↑/↓ — канал с непрочитанным,
  меню пользователя по правой кнопке (долгому нажатию), автостатус «Не активен» через 10 минут простоя
- устанавливается как приложение (PWA): манифест, иконки, service worker с оболочкой приложения
  (API, WebSocket и файлы — всегда из сети), предложение обновиться до новой версии, счётчик на значке

Голос и звонки работают только по **HTTPS** (или на `localhost`): без защищённого соединения браузер
не даёт микрофон, и клиент подскажет, в чём дело. Протокол и совместимость с десктопом —
[docs/CALLS.md](../docs/CALLS.md). Звонок из браузера на десктоп старой версии не соединится
(клиент сообщит об этом) — десктоп нужно обновить; звонки с десктопа в браузер работают.

## Разработка

```bash
cd web
npm install
npm run dev            # http://localhost:5173, API проксируется на http://localhost:8080
# другой бэкенд:
VICINITY_BACKEND=http://IP_VPS:8080 npm run dev
```

`npm run build` — проверка типов и сборка в `web/dist` (вместе с `sw.js` из `pwa/sw.js`: в него
подставляются версия сборки и список ассетов). Service worker регистрируется только в собранной
версии и только в защищённом контексте (HTTPS или `localhost`).

Иконки приложения в `public/icons/` нарисованы скриптом без зависимостей: `npm run icons`.

E2E-тесты (Playwright) поднимают собранный бэкенд и `vite preview`:

```bash
VICINITY_SERVER_BIN=../build/backend/VicinityServer npx playwright test
```

## Продакшен

Собирается и раздаётся nginx-контейнером из `deploy/` (сервис `web`), который проксирует
`/api`, `/ws` и `/uploads` на сервер. Инструкция — в [DEPLOY-VPS.md](../DEPLOY-VPS.md#веб-версия).
